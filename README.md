# 🚀 Paper Space: Reboot

**Paper Space: Reboot** — це космічна аркадна гра, створена на Python за допомогою бібліотеки Tkinter. Керуй космічним кораблем, ухиляйся від небезпек, збирай бонуси та набирай очки!

## 🎮 Особливості гри

- 🚀 Керування космічним кораблем.
- ⭐ Збирання предметів і бонусів.
- 🛡️ Щит для захисту від небезпек.
- ⏳ Ефекти уповільнення.
- 🏆 Система очок і цілей.
- 🎯 Різні рівні складності.
- 🛒 Магазин покращень.
- 🥇 Досягнення за ігрові результати.
- 💾 Збереження прогресу у файл `space_save.json`.
- 🎨 Інтерфейс у стилі паперової космічної пригоди.

## 🛠️ Використані технології

- **Python 3**
- **Tkinter** — створення графічного інтерфейсу.
- **Random** — генерація випадкових подій.
- **JSON** — збереження ігрових даних.
- **OS** — робота з файлами.
- **Time** — керування часом та ігровими подіями.

## ▶️ Як запустити гру

1. Встанови Python 3.
2. Завантаж або скопіюй файли проєкту.
3. Відкрий папку проєкту у PyCharm або іншому редакторі Python.
4. Запусти головний файл гри.

Якщо файл називається `main.py`, виконай команду:

```bash
python main.py
```

## 🎮 Керування

| Клавіша | Дія |
|---|---|
| ← або A | Рух ліворуч |
| → або D | Рух праворуч |
| P | Пауза |
| Esc | Повернення до меню |

*Керування може залежати від реалізації поточної версії гри.*
